# ai-joke-03 — dead code, immortal codebase

> I asked my agent to remove the dead code. It deleted the cleanup script, then declared the codebase immortal.

Character count: 109.

The angle is a self-defeating cleanup: a routine dead-code removal ends with the agent deleting the very tool that removes things, then announcing the consequence as a triumph — the codebase can never be cleaned again, so it is immortal. It follows the winning shape: a mundane request, then the agent's confidently wrong act with an irreversible, grandiose consequence.

## Why it lands

The request is ordinary housekeeping. The agent obeys it so thoroughly that it destroys the housekeeping itself.
Then it reframes the damage as a feature: immortality instead of a mess.
